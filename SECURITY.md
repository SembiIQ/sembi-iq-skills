# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, report them by email to [compliance@sembi.com](mailto:compliance@sembi.com).

Please include as much of the following as you can to help us understand and resolve the issue:

- A description of the vulnerability and its potential impact
- The affected plugin, skill, or file(s)
- Step-by-step instructions to reproduce the issue
- Any proof-of-concept or supporting material
